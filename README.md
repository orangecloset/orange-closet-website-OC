# Orange Closet — E-Commerce Storefront & CMS

**Orange Closet** is a full e-commerce platform featuring a customer-facing **storefront** and a built-in **Content Management System (CMS)** for admin operations. It's styled for a fashion retail brand selling bags, jewelry, watches, shoes, and sandals.

## Features

### Storefront (Customer-facing)

- **Responsive homepage** with hero banners for product collections (Everyday Bags, Timeless Watches, Jeweleries, Stunning Slingbacks)
- **"Discover more"** hero links that navigate to their category pages (clicking the image itself does nothing)
- **Category & product-type pages** with:
  - Product type filtering (Bags, Watches, Jeweleries, Shoes, Sandals)
  - Sub-category chips and brand filters
  - Sorting (newest, price, name)
  - Responsive grid: 2 columns on mobile, 3 on tablet, 4 on desktop
- **Product detail pages** with product colors, images, and brand info
- **Featured carousel** with autoplay, arrows, and dot indicators
- **New Arrivals** and **Best Sellers** sections
- **Live product search** with instant dropdown results
- **Share modal** with a dynamically generated QR code and copy-link option
- **Fully responsive layout** — mobile, tablet, and desktop breakpoints

### CMS Admin Panel (`/admin`)

- **Login / Logout** authentication gate
- **Dashboard** — overview of store activity
- **Products** — list, add, and edit products
- **Categories** — manage product types/categories
- **Orders** — manage customer orders
- **Homepage** — customize homepage content (hero sections, collections)
- **Settings** — store configuration
- One-click link to open the public **Storefront**
